TOMÁS OVIEDO — BARBERÍA · TURNOS

ARCHIVOS
- index.html: página del CLIENTE (solo ver horarios y pedir turno por WhatsApp). Sin nada de administrador.
- admin.html: página del ADMINISTRADOR (login, agendar, eliminar, copiar disponibilidad).
- firestore.rules: reglas de seguridad de Firestore (no cambiaron).

CÓMO ACTUALIZAR GITHUB PAGES
1. Entrá al repositorio Barberia-Turnos en GitHub.
2. Reemplazá index.html y subí admin.html (Add file > Upload files).
3. Commit changes. Esperá unos minutos y recargá con Ctrl+F5.
4. El cliente usa  https://TU-USUARIO.github.io/Barberia-Turnos/
   Vos entrás por  https://TU-USUARIO.github.io/Barberia-Turnos/admin.html  (no compartas este link).

CAMBIOS DE ESTA VERSIÓN
- Los horarios que ya pasaron se ponen en gris en TODA la semana (días anteriores completos y, hoy, las horas ya transcurridas). Al cliente también se le ven en gris los turnos ocupados que ya pasaron.
- Página separada para el cliente y para el administrador.

NOTA DE SEGURIDAD
Separar los archivos oculta el panel, pero la seguridad real sigue estando en las reglas de Firestore (solo el admin puede escribir y ver nombres).
